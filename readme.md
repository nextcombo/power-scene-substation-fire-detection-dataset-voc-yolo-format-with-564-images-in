# Power Scene Substation Fire Detection Dataset VOC+YOLO format with 564 images in 2 categories

Dataset format: Pascal VOC format + YOLO format (txt file without split path, only containing jpg images and corresponding VOC format xml files and yolo format txt files)

Number of images (number of jpg files): 564

Number of annotations (number of xml files): 564

Number of annotations (number of txt files): 564

Labeling category count: 2

Label category names (Note that the order of categories in the YOLO format does not correspond to this, but is based on the labels folder's classes.txt): ["fire", "smoke"]

Number of boxes and the number of images occupied by each category:

Fire frame count = 407, occupying image count = 395

Smoke frame count = 470, occupying image count = 460

Total frame count: 877

Image resolution: 640x640

Using labelImg:

Annotation rules: Draw a rectangle around the category.

Important Notice: The dataset does not have separate training, validation, and test sets; you need to partition them yourself.

Special : This dataset does not guarantee the accuracy of the trained models or weight files.
